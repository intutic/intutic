Intutic PII detectors — false-positive baseline
===============================================

Produced by:
    cd packages/proxy && INTUTIC_WRITE_BASELINE=1 cargo test --test pii_corpus_test

Every detector runs on every row with all detectors enabled, whatever its
default (card, IBAN and SSN ship on; email and phone ship off). A cell is
the number of rows with at least one validated match.

The first four corpora are external (see PROVENANCE.md). Their rows carry
no real PII, but BFCL's API tasks do pass made-up emails and phone numbers
as arguments, so a firing there can be a correct detection of a fake value;
every firing row is listed below so it can be read. The last corpus is
self-authored coding-agent traffic with no PII in it at all: a firing there
is a false positive. Its authors also wrote the detectors.
