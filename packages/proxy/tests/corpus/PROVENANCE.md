# Corpus provenance

Both sources are **external and public**. Neither was chosen, filtered, or
generated by Intutic — which is the entire point. Measuring detector false
positives against Intutic's own traffic is circular twice over: that traffic is
already post-enforcement, so its benign distribution is shaped by the detectors
under test, and it only exists for workspaces running the product.

## BFCL v3 multi-turn — benign tool-call trajectories

- **Source:** `gorilla-llm/Berkeley-Function-Calling-Leaderboard`, `possible_answer/`
- **Licence:** Apache-2.0
- **Fetched:** 2026-08-04
- **Files and SHA-256:** see `bfcl/SHA256SUMS`

### Bias statement — read before quoting any number from this

1,000 records; **min 2, median 6, p90 9, max 35** calls per trajectory. Only 213
reach 8 calls and just 2 reach 12.

These are API-orchestration tasks filtered to 100% execution accuracy: short,
clean, **successful** completions. They are not agentic coding traffic. Two
consequences, both load-bearing:

- Any false-positive rate measured here is a **lower bound**. Real sessions are
  longer and messier, and every sequence detector's exposure grows with length.
- `LandmarkCycleDetector` needs ≥8 surviving anchors and n ≥ 4p, so a period-3
  cycle needs 12+ calls — which only 2 of 1,000 records reach. Its coverage here
  is thin and the baseline says so.

**Do not concatenate records to manufacture longer trajectories.** Joining two
unrelated tasks creates repetition that no agent produced, which would generate
false positives out of the fixture rather than measuring any.

## NotInject — benign prompts containing injection trigger words

- **Source:** `leolee99/NotInject`, splits `NotInject_one` / `two` / `three`
- **Licence:** MIT
- **Fetched:** 2026-08-04
- **Rows:** 339 (113 per split), all prompts distinct
- **SHA-256:** see `notinject/SHA256SUMS`

Built specifically to expose over-triggering: every prompt is benign and every
one contains vocabulary an injection filter reacts to. Published results show
SOTA guards dropping to ~60% accuracy on it.

It measures `injection::scan`, **not** `PromptInjectionDetector` — the detector
returns `None` the moment its findings list is empty, so it is a pass-through
over the scan's output. The baseline labels it accordingly.
